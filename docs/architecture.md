# Архитектура Stage I

Цель — связать МРТ-находки с потенциально затронутым корешком. Подробные границы и анатомические правила см. в [scope](stage-1-scope.md).

| Стадия | Предполагаемая задача | Текущее состояние |
|---|---|---|
| Локализация | Определение уровней L1–S1 с использованием SpineNet / SpineReport | Не подключена |
| Анализ дисков | Адаптация LDH-DL-MODEL на YOLOv8 для признаков грыжи | Не подключён |
| Стенозы | Оценка фораминального и субартикулярного стеноза с каждой стороны на основе подходов RSNA | Не подключены |
| Fusion | Явные анатомические правила для объединения результатов стадий | Не реализован |

Следующий шаг — согласовать контракт исследований и результатов (C001), параллельно проверить доступность, лицензии, входы и ограничения выбранных моделей. Реальные адаптеры появятся по результатам этих задач.

## Harness сейчас

`scripts/harness.py` предоставляет `doctor`, `status`, `check` и `smoke`. Очередь и зависимости хранятся в `harness/tasks.json`. Проверки используют стандартную библиотеку Python.

Smoke читает синтетический manifest из `harness/fixtures/` и проверяет создание и повторное чтение служебного артефакта. Это артефакт harness, а не результат MRI pipeline:

- `kind`: `harness_smoke`;
- `synthetic`: `true`;
- `inference_performed`: `false`;
- `root_impacts`: `null`;
- `stages`: `localization`, `disc_analysis`, `stenosis`, `fusion` со статусом `not_configured`.

В репозитории пока нет stub pipeline приложения. Успех проверки harness не подтверждает качество локализации, классификации или fusion.

## Требования к будущим результатам

Контракт должен сохранять уровень, сторону, происхождение находок и ограничения входных данных. Отсутствующая серия, неподключённая модель, ошибка обработки и противоречивые результаты должны оставаться явно неопределёнными. `null` в текущем служебном артефакте нельзя трактовать как отсутствие воздействия.

Проверка точности будущих модулей входит в план технической оценки E001. Пациентская апробация пока не входит в обязательный план. Клинические симптомы, осмотр, ЭМГ и подтверждение радикулопатии относятся к Stage II.
