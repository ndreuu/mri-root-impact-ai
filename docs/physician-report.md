# Краткий отчет для врача

Каждый успешный `scripts/fuse_mri.py` автоматически сохраняет `report.html`, `report.md`, `fusion.json`, `report-evidence.json` и `run.json`.

В HTML ровно четыре раздела:

1. **Диски:** все пять уровней, результат, Axial T2 кадр. LDH не подключен; грыжа не считается отсутствующей.
2. **Фораминальный стеноз:** пять уровней, отдельные левая/правая степени и Sagittal T1 изображения.
3. **Субартикулярный стеноз:** пять уровней, отдельные левая/правая степени и Axial T2 изображения.
4. **Fusion:** только проблемы и короткие строки «находки ⇒ вывод».

Для выраженного стеноза вывод — потенциальное воздействие; неподтвержденная привязка отмечена как предположение. Для умеренного — соответствующий по анатомии корешок и «воздействие не определено». Normal/Mild не выводится в список проблем и не означает исключения воздействия.

Общие ограничения указаны один раз. Подробные исходные оценки, вероятности, источники и SHA доступны по JSON-ссылкам; длинные объяснения не включаются в основной отчет. Снимки встроены в HTML; Markdown ссылается на проверенные локальные PNG. Модель использует SagT1, SagT2 и AxT2; рамки показывают ее входные ROI.

## Запуск

```sh
open /Users/andrew/Datasets/mri-root-impact-ai/rsna-3139265320/fusion/f005-001/report.html
```

Из корня репозитория:

```sh
MRI_CASE=/Users/andrew/Datasets/mri-root-impact-ai/rsna-3139265320
python3 scripts/fuse_mri.py \
  --study "$MRI_CASE/prepared/study.json" \
  --spinenet-run "$MRI_CASE/localization/l002-001" \
  --rsna-run "$MRI_CASE/stenosis/s003-001" \
  --crosscheck-run "$MRI_CASE/geometry/l003-001" \
  --output "$MRI_CASE/fusion/f005-001" \
  --verify-only
```

Для нового запуска убрать `--verify-only` и указать новую папку. Версия представления — 1.2. Проверка повторно получает исходные данные и изображения, сравнивает все четыре артефакта и не пишет файлы.

Дисковые кадры связаны с `keypoint.native_level`. Метка `center` обозначает точку, а не уровень диска. Formal fusion JSON и policy не изменены. Исторические F002/F003/F004 сохранены и проверяются их кодом: `0d61c27`, `d0d3129`, `28bb52c`.
