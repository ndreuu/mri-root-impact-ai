# Краткий отчет для врача

Каждый успешный `scripts/fuse_mri.py` автоматически сохраняет `report.html`, `report.md`, `fusion.json`, `report-evidence.json` и `run.json`.

В HTML ровно четыре раздела:

1. **Диски:** все пять уровней, бинарное предсказание SpineNet и реальный Sagittal T2 вход модели. Размер, сторона и тип неизвестны. Без grading показывается «не оценена».
2. **Фораминальный стеноз:** пять уровней, отдельные левая/правая степени и Sagittal T1 изображения.
3. **Субартикулярный стеноз:** пять уровней, отдельные левая/правая степени и Axial T2 изображения.
4. **Fusion:** только проблемы и короткие строки «находки ⇒ вывод».

Для выраженного стеноза вывод — потенциальное воздействие; неподтвержденная привязка отмечена как предположение. Для умеренного — соответствующий по анатомии корешок и «воздействие не определено». Normal/Mild не выводится в список проблем и не означает исключения воздействия.

Общие ограничения указаны один раз. Подробные исходные оценки, вероятности, источники и SHA доступны по JSON-ссылкам; длинные объяснения не включаются в основной отчет. Снимки встроены в HTML; Markdown ссылается на проверенные локальные PNG. Стенозная модель использует SagT1, SagT2 и AxT2; рамки показывают ее входные ROI. Grading дисков использует SagT2, картинка — пятый из девяти фактических входных срезов. Положительный признак грыжи добавляется к фактам fusion с неизвестной стороной и не формирует корешковый вывод самостоятельно.

## Запуск

```sh
open /Users/andrew/Datasets/mri-root-impact-ai/rsna-3139265320/tool/d004-001/fusion/report.html
```

Из корня репозитория:

```sh
MRI_CASE=/Users/andrew/Datasets/mri-root-impact-ai/rsna-3139265320
python3 scripts/run_mri.py \
  --study "$MRI_CASE/prepared/study.json" \
  --config "$MRI_CASE/tool-config/inference-disc.json" \
  --output "$MRI_CASE/tool/d004-001" \
  --verify-only
```

Для нового полного запуска убрать `--verify-only` и указать новую папку. Версия представления — 1.3. Проверка повторно получает сохраненные исходные данные и изображения, сравнивает все четыре артефакта и не пишет файлы; нейросети не повторяет.

Без grading дисковые AxT2 кадры связаны с `keypoint.native_level`, а не `label=center`. С grading используются проверенные входы SpineNet. Formal policy не меняется; JSON дополнен raw дисковыми оценками и bindings.
