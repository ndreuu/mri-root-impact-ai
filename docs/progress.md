H001 выполнен: создан каркас отдельного локального репозитория. Добавлены карта проекта, границы Stage I, очередь с зависимостями, команды harness и правила хранения данных и весов.

Проверено на Python 3.9.6 и Git 2.50.1 без установки пакетов и сети:

- `make check` — 15 тестов, проверка очереди, состава файлов Git, пробелов и синтетического smoke проходят. Пустой набор тестов завершает проверку ошибкой.
- `make smoke` — служебный JSON-артефакт записывается и читается; `inference_performed=false`, `root_impacts=null`, все MRI-модули `not_configured`.

Независимый review выявил два случая, которые исправлены и покрыты регрессиями: пустой discovery тестов и некорректный тип статуса задачи. Модели не подключены; MRI inference не выполнялся. Успех harness не подтверждает качество MRI-модулей.

### C001 — контракты исследований и результатов

C001 выполнен. Добавлен пакет `mri_root_impact` с валидатором manifest исследования и результатов отдельных модулей. Сохраняются уровень, сторона, зона, исходный класс и шкала, измерения с единицами, источники изображений, версия модели и зависимости от локализации. `assessed`, `indeterminate`, `not_run`, `error` имеют разные требования; неполные данные не становятся отрицательной находкой.

Добавлены CLI `python3 -m mri_root_impact validate`, `make contracts`, документация и четыре синтетических результата: локализация, исходная оценка класса, неопределенный результат с сохраненным классом и пропущенный запуск при отсутствии Axial T2. `make check` автоматически проверяет эти примеры.

Проверки: `make check` — 36 тестов проходят (21 новый тест контрактов); `make contracts` и `make smoke` проходят без сети и новых зависимостей. Независимый review выявил противоречивую привязку к дисковому уровню upstream-локализации; исправление покрыто тестом. Также проверены отсутствие модели без фиктивного веса, строгий JSON, границы кадров, циклы и недостающие ссылки. Вызов `check` исправлен для импорта пакета из корня репозитория.

Гарантии ограничены структурой и связностью метаданных: файлы изображений не открываются, пригодность последовательностей и семантика исходных классов не подтверждаются. Геометрия локализатора остается в L001, итоговый формат вывода о корешке и пороги — в F001. MRI inference не выполнялся.

### I001 — исследование для воспроизводимого запуска

I001 выполнен. Проверены локальные SPIDER и Sudirman; после уточнения пользователя выбран публичный Hugging Face mirror RSNA, закрепленный по revision `e881937c3222a5fc1c09d573adac3b9a1ff50d35`. Контрольный study `3139265320` содержит 15 Sagittal T2/STIR, 15 Sagittal T1 и 30 Axial T2. Снимки (3 560 654 байта), 3 таблицы выбранного случая и provenance хранятся вне Git в `/Users/andrew/Datasets/mri-root-impact-ai/rsna-3139265320`.

Добавлен загрузчик HTTP Range с ограничением объема, проверкой ZIP64/CRC и локальных SHA-256. После сетевых таймаутов чтение DICOM объединено в один ограниченный блок. Полный архив около 30,3 ГБ не скачивался, его полная контрольная сумма не объявляется проверенной. Исходные DICOM сохранены без изменений.

Добавлены `prepare-rsna` и `preflight`: C001 manifest проходит проверку, все 60 файлов проходят SHA-256 и декодирование. В исходниках отсутствует тег Modality; явный `--allow-missing-modality` сохраняет `modality_status=dataset_declared`. Дефолтная проверка остается строгой и отклоняет CT даже при включенном флаге. Аксиальная серия имеет шесть ориентаций; `registration_status=needs_review`. Модели не запускались, `full_stage_i_input=false`.

Команды и ограничения зафиксированы в [docs/control-study.md](control-study.md), версии дополнительных зависимостей — в `requirements-data.txt`. Перепроверка источника работает через `--verify-only` без сети. Независимый review выявил и помог закрыть риск перезаписи исходного снимка выходным отчетом; он покрыт регрессией.

Проверки: базовый `make check` на Python 3.9.6 — 65 тестов проходят, 9 тестов декодера пропускаются без дополнительных зависимостей. С pydicom 3.0.2 и NumPy 2.5.3 на Python 3.12.14 проходят все 74 теста, примеры контрактов и synthetic smoke. Реальные DICOM в тестовый набор и Git не включены.

В локальном репозитории создано отдельное окружение `.venv-data` с закрепленными зависимостями. После переноса в постоянный каталог повторно выполнены подготовка manifest, декодирование 60 DICOM, проверка C001 и offline `--verify-only`.

## 19 октября 2026

### L001 — аудит и выбор локализатора

L001 выполнен. Для первого исследовательского запуска выбран SpineNet `detect_vb`, commit `5e96ac54b1c1845a37d12e40bfd16f647d40acd8`. Проверены код API, условия использования, четыре официальных URL весов (HEAD 200) и локальные checkpoints: 821 857 187 байт, все SHA-256 повторно вычислены. Inventory закреплен в `harness/upstreams/spinenet.json`; сами веса остались вне Git.

SpineNet возвращает метки и четырехугольники тел позвонков по срезам, без voxel masks. Его лицензия ограничивает код, веса и outputs некоммерческими исследованиями; продуктовый перенос не утверждается. SpineReport оказался reporting-слоем по готовым маскам; TotalSpineSeg проверен как альтернативный сегментатор. Их версии, условия, API и ограничения зафиксированы в [docs/localizer-audit.md](localizer-audit.md).

Без импорта модели выполнен реальный IO-прогон обеих сагиттальных серий RSNA: по `256×256×15`, PixelSpacing 1.0156 мм, единая ориентация, исходные SHA не изменились. Обнаружено различие SliceThickness 4 мм и физического шага центров около 5 мм. Upstream сортирует InstanceNumber и усредняет spacing; адаптер L002 должен сохранить физическую геометрию и явные ссылки на исходные кадры. Отчет и программа IO-аудита — во внешнем `prepared/l001/` контрольного исследования.

Найдено локальное окружение NumPy 1.26.4 / Torch 2.5.1; текущая `.venv-data` с NumPy 2.5.3 несовместима с неизмененным `ndarray.ptp()` upstream. Новый runtime и spatial contract будут частью L002. В L001 выполнены `make check` и `make smoke`: базовый Python — 65 проходят, 9 optional пропущены; с `.venv-data` проходят все 74 теста. Независимый review документации и inventory не выявил блокеров. Нейросетевой inference, оценка полноты L1–S1 и overlay еще не выполнялись.
