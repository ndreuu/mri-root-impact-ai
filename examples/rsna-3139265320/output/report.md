## 4. Fusion

- L3–L4 + умеренный фораминальный стеноз слева + признак грыжи \(SpineNet; сторона неизвестна\) ⇒ выходящий корешок L3 слева.
- L3–L4 + умеренный субартикулярный стеноз слева + признак грыжи \(SpineNet; сторона неизвестна\) ⇒ проходящий корешок L4 слева.
- L4–L5 + умеренный фораминальный стеноз слева ⇒ выходящий корешок L4 слева.
- L4–L5 + умеренный субартикулярный стеноз слева ⇒ проходящий корешок L5 слева.

† Условная анатомическая привязка; нумерация/совмещение требуют подтверждения.
Норма/лёгкий — единый класс, не исключает изменений. ROI — вход модели, не разметка патологии. Модель: SagT1/SagT2/AxT2.
