# Данные

Данные исследований и пациентов хранятся вне Git и вне этого репозитория. Этот каталог содержит только описание правил; он не предназначен для загрузки МРТ.

В `harness/fixtures/` допустимы только синтетические manifest-файлы без изображений исследований, идентификаторов пациентов и извлечённых медицинских данных. Текущий smoke не анализирует МРТ.

Формат входного manifest реализован в [C001](../docs/contracts.md). Задача I001 в [очереди](../harness/tasks.json) — подобрать исследование для воспроизводимого запуска: проверить источник, серии и покрытие, сохранить внешний путь и контрольные суммы, подготовить валидный manifest и команды повторной проверки.

Проверка расширений файлов в harness не гарантирует отсутствие чувствительных данных: перед коммитом нужно просматривать состав изменений.
