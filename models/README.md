# Модели

Модели пока не подключены. Этот каталог содержит документацию; веса, кэши и скачанные артефакты должны храниться вне Git и вне репозитория.

Задачи L001, D001 и S001 проверят доступность SpineNet / SpineReport, LDH-DL-MODEL и подходов RSNA. Для выбранного артефакта нужно будет зафиксировать источник, лицензию, версию или контрольную сумму, ожидаемые входы и способ воспроизведения запуска.

Статус `not_configured` в smoke означает отсутствие настроенного модуля. Он не является результатом применения модели к исследованию.
